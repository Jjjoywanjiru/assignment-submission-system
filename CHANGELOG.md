# Changelog

All notable changes to this project are recorded here.

## v1.3.1 (to tag after the pull requests are merged)
- Added an **Edit** button on My submissions, shown only before the deadline.
- Recorded the recovery from a deliberately faulty change (CR-002): the bad
  commit and its `git revert` are kept in history. No net code change.
- Added `docs/change-requests/CR-001-edit-submission.md` and
  `docs/recovery-report.md`.

## v1.3
- Students can edit a submission (replace the file and/or change the comment)
  until the deadline (CR-001). Edits after the deadline are blocked.
- Added README, requirements and user guide.

## v1.2
- Student assignment submission: list assignments, upload work, late check,
  submission status.

## v1.1
- Lecturer assignment management: create assignments, view and download
  submissions.

## v1.0
- Registration, login and logout.
